# 任务卡：海报和 PPT（视觉同学）

## 先看 README
产品是什么、演示怎么走，都以 [README](../README.md) 为准。**不做的东西**：数字人、3D 形象、登录后台。

## 海报（周六晚提交给组委会）
- 一句话：**小屿，一个有记忆的陪伴伙伴。它住在故事里，也坐在你桌上。**
- 画面主体：网页故事和桌上机器人，中间用一条"记忆"把两边连起来。
- 三个卖点：故事和身体共用一份记忆；它能读懂你的情绪；记忆单独保存、不被别人看到。
- 尺寸和格式：先问组委会；问不到就按竖版 A3。

## 路演 PPT（周日 11:00 前定稿）
专家评审每队 8 分钟讲解和演示、2 分钟提问。评分权重：问题与价值 20，创意 20，完成度 25，AI 与技术 20，现场展示 15。

建议 6 到 8 页：
1. 问题：AI 陪伴要么在屏幕里没有身体，要么是机器人却不记得你。
2. 小屿是什么（就是 README 里那一句）。
3. 演示三步（故事 → 机器人 → 故事）。这一页由 LH 现场演示。
4. 怎么做到的：一份记忆本，两边共用；情感模块。
5. 记忆单独保存，每个人的数据互相隔离。
6. 下一步。

做完把文件发给 LH，或者提交到本仓库的 `docs/展示/` 目录。
