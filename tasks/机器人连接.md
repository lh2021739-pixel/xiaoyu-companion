# 任务卡：机器人连接（机器人同学）

## 做什么
让演示用的 Mac 能直接控制硅胶头：说话、做表情。**不用你的云端对话服务**，对话由 Mac 自己负责，只借用机器人的身体。

## 我们已经确认的
- 头部控制程序 `hardware/head_motion_bridge.py` 在 Mac 上能跑起来，空跑模式下微笑、难过等指令都能正常收发。
- 连真机需要 adb 通过 WiFi 连到头部（`<头部IP>:5555`）。

## 需要你提供
1. 头部的 **IP 地址**，以及 adb 怎么连（端口是不是 5555、需不需要先开调试模式）。
2. 现场的网络怎么解决：头部和 Mac 必须在同一个局域网。我们打算带随身路由器或开手机热点，头部要怎么切换到这个网络？
3. 头部怎么供电、怎么开机，开机后多久能连上。
4. 比赛当天你能不能到场，或者能不能远程支援半小时，陪我们把第一次连接跑通。

## 怎么算做完
在演示用的 Mac 上，通过 adb 方式启动头部控制程序，能同时做到：
- 发"微笑"，头部真的笑了；
- 发一段语音，头部喇叭播出声音，嘴巴跟着动。
