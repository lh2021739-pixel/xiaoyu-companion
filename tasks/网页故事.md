# 任务卡：故事平台（第 2 项）

## 做什么
1. 故事主线：现实世界背景，玩家在交流中逐步发现和妻子的经历，故事最后指向亡妻结局。
2. **一键导出**：故事结束后，玩家选一个角色（演示时选亡妻），把这个角色的人设和与玩家的全部经历导出，导入记忆库。
3. 导出后，故事平台和机器人就分开了，机器人里的聊天不会回到网页。

## 导出格式
**由你来定。** 下面是记忆库现在能直接接收的格式，仅供参考。你定好格式后告诉 LH，记忆库这边按你的格式来接。
```json
{
  "character": {
    "id": "wife_001",
    "name": "角色名",
    "call_user": "她对玩家的称呼",
    "personality": "性格",
    "speaking_style": "说话方式",
    "background": "她的身份和经历",
    "relationship": "和玩家的关系",
    "ending": "故事的结局（例如她已经离开，自己也清楚）",
    "guidance": "现在和玩家相处的方式（例如温柔陪他回忆，鼓励他好好生活）",
    "voice": {"provider": "dashscope", "voice": "Cherry"}
  },
  "events": [
    {"summary": "一句话写一段共同经历，按时间顺序", "importance": 1到3}
  ]
}
```
- **导入接口**：`POST http://127.0.0.1:8900/characters/import`，请求体就是上面的 JSON。导入后，这个角色自动成为机器人的"当前角色"。
- 完整的虚拟示例见 [tools/sample_characters/wife_test.json](../tools/sample_characters/wife_test.json)。
- 只有玩家真正看到、真正经历过的剧情才导出。生成了但没展示给玩家的，不要导出。

## 自己怎么测
```
python3 memory/memory_server.py          # 启动记忆库，只需要 Python，不用装任何包
# 平台点"一键导出"，或者用下面这条命令导入示例：
python3 tools/import_character.py tools/sample_characters/wife_test.json
curl --noproxy '*' 'http://127.0.0.1:8900/context?for=robot'   # 看机器人会读到什么
```
`persona_text` 是她的人设，`memory_text` 是她的记忆，两样都对，就说明导出成功了。
