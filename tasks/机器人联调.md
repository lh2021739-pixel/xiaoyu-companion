# 任务卡：机器人联调（第 5 项）

> **状态（11.21）：已跑通。** 双击 `tools/双击启动.command` 就能连上机器人：表情、喇叭出声、嘴巴联动、用机器人自己的麦克风收音都在真机上测过。下面是细节和排错。

## 做什么
让演示用的 Mac 直接控制硅胶头机器人：说话（嘴跟着动）、做表情。对话由 Mac 上的机器人大脑负责，机器人只当"身体"，不需要它原有的云端对话服务。

## 现在的基础
- 头部控制程序 `hardware/head_motion_bridge.py`（在 AI-Lover 仓库里）可以在 Mac 上运行。空跑模式下，微笑、难过等指令都能正常收发。
- 真机连接：Mac 通过 adb 走 WiFi 连到头部（`<头部IP>:5555`）。
- 大脑会发出这些指令：表情 `smile / sad / makeface / kiss / blink / init`；说话时通过 `/audio/play` 把声音发给头部喇叭，并带动嘴巴。

## 需要弄清楚并跑通的
1. 头部的 IP，adb 怎么连（端口是不是 5555，要不要先打开调试模式）。
2. 现场网络：头部和 Mac 必须在同一个局域网。建议带随身路由器或开手机热点。
3. 头部怎么供电、怎么开机，开机后多久能连上。
4. 有问题时怎么联系机器人原作者。

## 跑通的步骤（11.21 已在真机跑通：表情、喇叭出声、嘴巴联动）
这台头部的主板是 RK3566（LubanCat-1N），声卡和孙博程序的默认设置不一样，**必须加下面两个开关**，不然喇叭不出声：
- `HEAD_AUDIO_PLAYBACK_SETUP="tinymix -D {card} 'Playback Path' SPK_HP"`：切换播放通道。**这台的喇叭接在耳机输出（HP）上，只选 SPK 没声音**，选 SPK_HP 或 HP 才有声（11.21 实测）。默认设置里的音量开关在这块声卡上不存在，会报错
- **机器人自带的对话应用（`org.zksj.robot`）必须停掉**：它运行时会占住声卡，我们的声音放不出来，它自己也会抢着回答。停掉：`adb -s <头部IP>:5555 shell am force-stop org.zksj.robot`。机器人重启后它会自动恢复，所以每次演示前都要停一次；也别去点机器人上的画面，点了可能会把它重新打开
- `HEAD_AUDIO_PLAYBACK_SAMPLE_RATE=44100`：这块声卡只支持 44100Hz

- **机器人自己的麦克风**：大脑用 adb 在头部持续运行 `tinycap`（44100Hz 双声道，左声道是麦克风，右声道是喇叭回采），把声音流式传回 Mac。麦克风通道要设为 `Capture MIC Path = Hands Free Mic`，停掉自带应用后它会变成 `MIC OFF`，大脑启动时会重新打开。

头部 IP：`tools/find_head.sh` 会在 Mac 当前连的网络里自动找（开着 adb 5555 端口、型号是 LubanCat 的那台）。也可以在孙博网页"设置 → 硅胶头机芯 → 头部 IP"里看。11.21 先后用过 `172.20.10.5`（iPhone 热点）和 `192.168.43.179`（安卓热点），换网络就会变。机器人只会连它配过的热点；5GHz 热点也能连。

**机器人自带的对话应用**：`org.zksj.robot`，用的是火山引擎豆包角色模型（`doubao-seed-character`），有普通、打断、亲密三种模式（设置里的 `touch_model`）。它的人设在厂家那边，没法换成我们的人设和记忆，所以我们停掉它、只用机器人的身体。改它的设置文件关不掉它（应用一启动会把开关改回去），只能停掉应用本身。
```
# 1. 启动头部控制程序（Python 3.12 及以下，Mac 上已装 adb）
HEAD_MOTION_TRANSPORT=adb HEAD_MOTION_DRY_RUN=0 HEAD_MOTION_ADB_SERIAL=<头部IP>:5555 \
HEAD_AUDIO_PLAYBACK_SETUP="tinymix -D {card} 'Playback Path' SPK_HP" HEAD_AUDIO_PLAYBACK_SAMPLE_RATE=44100 \
python3 head_motion_bridge.py
# 2. 检查
curl --noproxy '*' http://127.0.0.1:8787/health         # transport 是 adb、dry_run 是 false 才算连上真机
curl --noproxy '*' -X POST http://127.0.0.1:8787/action -d '{"action":"smile"}'
# 3. 启动大脑时加上 HEAD_URL=http://127.0.0.1:8787（见 docs/运行说明.md）
```

## 怎么算做完
在演示用的 Mac 上：
- 发"微笑"，头部真的笑了；
- 和大脑对话时，头部喇叭出声，嘴巴跟着动，表情随对话变化。
