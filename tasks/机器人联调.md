# 任务卡：机器人联调（第 5 项）

## 做什么
让演示用的 Mac 直接控制硅胶头机器人：说话（嘴跟着动）、做表情。对话由 Mac 上的机器人大脑负责，机器人只当"身体"，不需要它原有的云端对话服务。

## 现在的基础
- 头部控制程序 `hardware/head_motion_bridge.py`（在 AI-Lover 仓库里）可以在 Mac 上运行。空跑模式下，微笑、难过等指令都能正常收发。
- 真机连接：Mac 通过 adb 走 WiFi 连到头部（`<头部IP>:5555`）。
- 大脑会发出这些指令：表情 `smile / sad / makeface / kiss / blink / init`；说话时通过 `/audio/play` 把声音发给头部喇叭，并带动嘴巴。

## 需要弄清楚并跑通的
1. 头部的 IP，adb 怎么连（端口是不是 5555，要不要先打开调试模式）。
2. 现场网络：头部和 Mac 必须在同一个局域网。建议带随身路由器或开手机热点。
3. 头部怎么供电、怎么开机，开机后多久能连上。
4. 有问题时怎么联系机器人原作者。

## 跑通的步骤
```
# 1. 启动头部控制程序（Python 3.12 及以下，Mac 上已装 adb）
HEAD_MOTION_TRANSPORT=adb HEAD_MOTION_DRY_RUN=0 HEAD_MOTION_ADB_SERIAL=<头部IP>:5555 python3 head_motion_bridge.py
# 2. 检查
curl --noproxy '*' http://127.0.0.1:8787/health         # transport 是 adb、dry_run 是 false 才算连上真机
curl --noproxy '*' -X POST http://127.0.0.1:8787/action -d '{"action":"smile"}'
# 3. 启动大脑时加上 HEAD_URL=http://127.0.0.1:8787（见 docs/运行说明.md）
```

## 怎么算做完
在演示用的 Mac 上：
- 发"微笑"，头部真的笑了；
- 和大脑对话时，头部喇叭出声，嘴巴跟着动，表情随对话变化。
