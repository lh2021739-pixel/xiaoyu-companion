# 任务卡：情感（情感同学）

## 做什么
让机器人小屿**像真人一样**接住主人的情绪。不用写代码，交的是**文字材料**，LH 直接放进机器人大脑里用。

## 机器人大脑现在怎么工作
主人说一句话以后，大脑拿到三样东西：
- **原话**（由语音转出的文字）；
- **语气标签**：本地语音识别顺带给出，可能是 开心 / 难过 / 生气 / 平静 等；
- **记忆本里的内容**：故事里发生过的事、两人的约定。

大脑每一轮都输出一段固定格式：
```json
{"emotion":"难过","expression":"sad","reply":"要说的话","remember":"这一轮值得记住的事，没有就空着"}
```
机器人能做的表情只有这几种：`smile` 微笑、`sad` 难过、`makeface` 鬼脸、`kiss` 亲亲、`blink` 眨眼、`init` 恢复平常。

## 实测时发现的问题（这就是你要解决的）
1. 主人说"我回来了"，小屿没有主动提起记忆里"约好去看海"的事。
2. 主人说"被老板骂了，好累"，被判成"累"，表情选了眨眼，没有选难过。
3. "被老板骂"这件事没有被记下来。
4. 回答里会出现表情符号（🥺），语音读不出来。

## 要交的四样东西
1. **小屿的人设**：一段文字，可以直接当系统提示词用。写清性格、说话方式（短、口语、一次一两句、不用表情符号），以及什么时候主动提起记忆。
2. **情绪规则**：原话和语气标签对不上时听谁的；每种情绪配哪个表情；每种情绪下回话的方式，比如难过时先共情、不讲道理、不急着给建议。
3. **什么要记、什么不记**：举例说明，比如"被老板骂"要记，"嗯嗯好的"不记。
4. **10 段测试对话**：每段写清主人说什么、带什么语气，以及期望的情绪、表情和回话方向。用来检验"像不像真人"。

## 怎么交、怎么改
- 写成文字发给 LH，或者直接提交到本仓库的 `docs/情感/` 目录。
- LH 放进去之后，你在他的 Mac 上照着 10 段测试对话逐段试聊。哪里不像真人，就改文字，改完马上能再试，不用改代码。
