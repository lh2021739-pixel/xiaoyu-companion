# 小屿：有记忆的陪伴伙伴

未来造物者 AI 黑客松 2026 北京站 · 成人组参赛项目

## 产品是什么
陪伴伙伴"小屿"同时出现在两个地方：**网页里的互动故事**和**你桌上的实体机器人**。两边是同一个它，记忆是共用的。

演示是这样的：
1. 在网页故事里，你答应小屿"周末陪你去看海"。
2. 转身对机器人说"我回来了，今天被老板骂了"。机器人做出难过的表情安慰你，还提起"你答应陪我去看海的"。
3. 回到网页，新的一章里，小屿提到了你被老板骂的事。

现在的 AI 陪伴，屏幕里的有故事、没身体；实体机器人有身体，却不记得你。小屿把**故事、身体、记忆**打通了。

## 产品由五块组成
| 块 | 是什么 | 负责 | 任务卡 |
|---|---|---|---|
| ① 机器人身体 | 硅胶头机器人，会说话、做表情 | 机器人同学 | [tasks/机器人连接.md](tasks/机器人连接.md) |
| ② 机器人大脑 | 听你说话 → 想怎么回 → 让机器人说出来、做表情 | LH | 不需要任务卡 |
| ③ 记忆本 | 两边共用的记事本：故事写进"你选了什么"，机器人写进"你说了什么"，两边开口前都先翻一翻 | LH | [docs/记忆本格式.md](docs/记忆本格式.md) |
| ④ 网页故事 | 能一直往下写的互动故事，每章开始前先翻记忆本 | 故事同学 | [tasks/网页故事.md](tasks/网页故事.md) |
| ⑤ 情感 | 从你的话和语气判断情绪，决定机器人做什么表情、怎么安慰你 | 情感同学 | [tasks/情感.md](tasks/情感.md) |
| 展示 | 海报（周六晚交）、路演 PPT | 视觉同学 | [tasks/海报和PPT.md](tasks/海报和PPT.md) |

所有部分最后都在演示用的那台 Mac 上运行，由 LH 负责串起来。

## 代码（LH 负责的部分）
| 目录 | 是什么 |
|---|---|
| `memory/memory_server.py` | 真记忆本（端口 8900），接口和 `tools/mock_memory_server.py` 一样 |
| `brain/` | 机器人大脑和演示控制台（端口 8910）。人设和情绪规则是 `brain/prompts/` 里的纯文字，改文字就能生效 |
| `run.sh` | 一条命令启动两者 |
| `tests/` | 端到端自测 |

怎么跑见 [docs/运行说明.md](docs/运行说明.md)，当前进度见 [docs/验收清单.md](docs/验收清单.md)。

## 每个人怎么用这个仓库
