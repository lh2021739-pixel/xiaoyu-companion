# 记忆陪伴：让故事里的人走进现实

未来造物者 AI 黑客松 2026 北京站 · 成人组参赛项目

## 产品是什么
玩家先在网页上体验一段故事。故事以现实世界为背景：你有一个妻子，你在故事里一点点找回你们的经历和回忆，故事最后，她离开了人世。

故事结束后，你可以从故事里选一个角色，一键导出她的人设和你们的全部经历，导入桌上的实体机器人。机器人从此就是她：记得你们的一切，也知道自己已经离开。她会温柔地陪你回忆，也会鼓励你好好生活。之后你和机器人聊的内容会继续存进她的记忆，但不再回到网页故事里。

一句话：**网页里的情感，投射到现实里的一个身体上。**

## 整体链路
```
网页故事平台 ──一键导出（人设 + 经历）──▶ 记忆库 ──当前角色的人设和记忆──▶ 机器人对话大脑 ──声音 + 表情──▶ 实体机器人
                                          ▲                                   │
                                          └──────── 新的聊天内容写回 ─────────┘
```
- 记忆库可以存多个角色，其中一个标记为"当前角色"。导入一个新角色，机器人就换成这个人，各角色的记忆互不混用。
- 演示和测试先用虚拟的亡妻角色 `tools/sample_characters/wife_test.json`。故事平台的一键导出做好后，换成真实角色。

## 代码（第 3、4 项）
| 目录 | 是什么 |
|---|---|
| `memory/memory_server.py` | 记忆库（端口 8900），只用 Python 自带库 |
| `brain/` | 机器人对话大脑和演示控制台（端口 8910）。通用说话规则和情绪规则在 `brain/prompts/`，是纯文字，改了就生效 |
| `tools/import_character.py` | 把一个角色文件导入记忆库 |
| `run.sh` | 一条命令启动记忆库和大脑 |
| `tests/` | 端到端自测 |

怎么跑见 [docs/运行说明.md](docs/运行说明.md)，当前进度见 [docs/验收清单.md](docs/验收清单.md)。
