# 记忆陪伴：让故事里的人走进现实

未来造物者 AI 黑客松 2026 北京站 · 成人组参赛项目

## 是什么
用户在网页上体验一段故事，故事里的人物（比如已经离开的妻子）连同她的人设和你们的全部经历，一起导入桌上的实体机器人。机器人从此就是她：记得你们的一切，也知道自己已经离开；会温柔地陪你回忆，也会鼓励你好好生活。之后和机器人聊的内容，会继续存进她的记忆。

```
故事平台 ──导出（人设 + 经历）──▶ 记忆库 ──人设和记忆──▶ 对话大脑 ──声音 + 表情──▶ 实体机器人
                                  ▲                          │
                                  └──── 新的聊天内容写回 ─────┘
```
- 记忆库可以存多个角色，其中一个是"当前角色"，各角色的记忆互不混用。
- 实体机器人只当"身体"：Mac 通过 WiFi（adb）用它的麦克风听、用它的喇叭说、让它做表情；对话、记忆、声音都在 Mac 上。
- 示例角色：故事一《重新认识一次》的林晚（`tools/sample_characters/story1_linwan.json`）。

## 代码
| 目录 | 是什么 |
|---|---|
| `memory/memory_server.py` | 记忆库（端口 8900），只用 Python 自带库。接口见 [docs/记忆库接口.md](docs/记忆库接口.md) |
| `brain/` | 对话大脑和演示控制台（端口 8910）：收音和断句、本地语音识别、人设对话、语音合成、机器人表情和出声。说话规则和情绪规则在 `brain/prompts/` |
| `brain/avatars/` | 角色照片，文件名是角色 id |
| `tools/import_character.py`、`tools/sample_characters/` | 把角色文件导入记忆库；示例角色 |
| `tools/双击启动.command`、`tools/双击关闭.command` | 一键启动 / 关闭（自动找机器人） |
| `tools/find_head.sh`、`robot_start.sh`、`robot_stop.sh` | 找机器人、启动、关闭 |
| `run.sh` | 一条命令启动记忆库和大脑；加 `HEAD_IP=` 时连机器人 |
| `tests/` | 端到端自测 |

怎么跑见 [docs/运行说明.md](docs/运行说明.md)。

机器人头的控制程序 `head_motion_bridge.py` 来自孙博团队的 AI-Lover 仓库，本仓库只调用它的接口。

**不要把任何 API Key 提交进仓库。**
