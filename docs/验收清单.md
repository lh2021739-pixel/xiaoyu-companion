# 验收清单（11.21 凌晨，记忆本 + 机器人大脑 + 演示控制台）

所有测试都在 LH 的 Mac 上跑：**静音、不开麦克风**。"主人说的话"用打字，或者用 macOS 自带的中文合成语音模拟。

## 做完、测过的
| 项目 | 结果 |
|---|---|
| 记忆本：写事件、两边取上下文、读过不重复给、清空 | 通过。格式不对的事件会被拒绝；内容相近的话不会重复记 |
| 记忆本：整理长期记忆（约定、喜好、关于主人、关系） | 通过。每次约 2 到 3 秒，在后台进行，不耽误对话 |
| 大脑·打字模式端到端（7 项检查，`tests/e2e_text.py`） | **最后连续 5 次全部 7/7 通过**。检查内容：打招呼时提起故事里的约定；判断出难过并做难过的表情；把"被老板骂"记进记忆本；能聊喜好；说晚安后结束相处；长期记忆里有约定和喜好；故事那边能取到机器人这边的新事 |
| 大脑·语音模式（`tests/e2e_voice.py`） | 本地识别每句约 0.45 秒。"我回来了""晚安"识别准确。"今天被老板当着大家的面骂了"识别错了几个字，但小屿仍然理解对了，记进记忆本的内容也对。这句是 macOS 合成音念的，不是真人，真人说话要你来测 |
| 故事 → 机器人 | 故事里"答应周末陪小屿去看海"之后，对机器人说"我回来了"，小屿会说"周末去看海的事，我一直记着呢"。专门测了开场的提示：qwen-flash 8 次里 8 次都提到了 |
| 机器人 → 故事（用备用的 AIstory） | 剧情引擎从真记忆本取到机器人这边的记忆，生成的下一章里，小屿端来热可可，并问"海……周末还去吗？" |
| 备用 AIstory 接入记忆本 | 已改：生成下一章前读记忆本；做选择后写进记忆本；默认关闭提前生成分支。首页和游玩页编译正常（200）。改动只提交在本地分支 `feasibility/shared-memory`，没有上传 |
| 演示控制台 | 宽屏三栏、窄屏单栏都能正常显示。内容有：小屿的表情脸、主人的情绪、对话（带每一步耗时）、记忆本（约定、喜好、事件）、打字框、开始/结束/清空按钮 |
| 机器人头控制程序（空跑） | 大脑发出的表情指令被接受。真机播放声音要等现场 |

## 速度（每说完一句，到小屿开口）
| 环节 | 耗时 |
|---|---|
| 本地识别 | 约 0.45 秒 |
| 想（qwen-flash） | 约 0.7 秒 |
| 语音合成：阶跃 | 约 1.9 秒 |
| 语音合成：百炼 | 约 1.0 秒 |
| **合计** | **阶跃约 3.1 秒，百炼约 2.2 秒** |

识别完会立刻应一声"嗯"，填补等待。

## 替你做的决定（不同意的话，一个开关就能改）
1. 对话模型默认用 **qwen-flash**：比 qwen-plus 快一倍，测试结果一样。改回用 `CHAT_MODEL=qwen-plus`。
2. 语音合成**保留你选的阶跃**，阶跃失败时自动换百炼。百炼快一倍，要换用 `TTS_PROVIDER=dashscope`。
3. 默认音色是阶跃的"温柔女声"。七种样本在 `../voice_samples/`，你醒来听一下再挑。
4. 加了"听完先应一声嗯"。不要的话用 `ACK=0` 关掉。
5. 备用 AIstory 默认关闭"提前生成后续分支"，否则提前生成的章节带不上刚和机器人聊的事。

## 需要你醒来做的
1. **听音色**：打开 `../voice_samples/`，挑一个，告诉我名字。
2. **开麦克风真人试一次**：
   - 运行 `PYTHON=<装好依赖的Python> ./run.sh`；
   - macOS 弹出麦克风权限时，点"允许"；
   - 说"我回来了""今天被老板骂了，好累""晚安"，看控制台和听声音。
3. **把仓库链接发给队友**（如果还没发）。
4. **找机器人同学要机器人头的 IP**，接法见 `docs/运行说明.md`。

## 还没做 / 已知问题
- 没有测真人说话和真麦克风：需要你点授权，而且半夜不能出声。
- 没有接真机器人头：要等 IP。
- 没有接故事同事的平台：要等他交付。他照任务卡做，接口和我们的记忆本一致。
- 判断出来的情绪偶尔是"累"而不是"难过"，但表情都选对了（难过）。情感同学交来规则后再细调。
- 外放时如果麦克风收到小屿自己的声音：小屿说话期间大脑会暂停收音，结束 0.3 秒后再恢复。现场如果仍有回声，可以把音量调小，或者让人凑近一点说。
