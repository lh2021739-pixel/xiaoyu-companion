# 模块说明：每块是什么、怎么单独拿去用

这个仓库里 LH 负责的部分（记忆库、对话大脑、机器人连接、演示控制台）拆成下面 7 个模块。每个模块都能单独拿到别的项目里用，下面写清楚：在哪些文件、对外接口、依赖、单独用时要注意什么。

| # | 模块 | 文件 | 依赖 |
|---|---|---|---|
| 1 | 多角色记忆库 | `memory/memory_server.py` | 只用 Python 自带库；整理长期记忆时调百炼 qwen-plus（可关） |
| 2 | 角色文件格式 | `tools/sample_characters/*.json`、`tools/import_character.py` | 无 |
| 3 | 人设对话（大模型） | `brain/llm.py`、`brain/prompts/*.md` | requests；百炼 qwen-flash |
| 4 | 听：收音 + 判断说完 + 本地识别 | `brain/audio_in.py`、`brain/asr.py` | numpy、sounddevice、scipy、funasr、torch；SenseVoiceSmall 模型 |
| 5 | 说：语音合成（主备音色）+ 播放 | `brain/tts.py`、`brain/output.py` | requests、numpy；百炼 / 阶跃 |
| 6 | 机器人头连接（adb） | `tools/find_head.sh`、`tools/robot_start.sh`、`tools/robot_stop.sh`、`run.sh`、`brain/audio_in.py` 里的 `HeadMicSource` | adb；孙博的 `head_motion_bridge.py` |
| 7 | 对话大脑 + 演示控制台（把 1 到 6 串起来） | `brain/brain.py`、`brain/config.py`、`brain/console.html` | 以上全部 |

## 1. 多角色记忆库
- **做什么**：存多个角色，每个角色有人设卡、记忆条目（故事里的经历 + 和机器人聊的）、长期记忆（关于他的事、喜好、约定、现在的状态）。其中一个是"当前角色"。
- **接口**：见 [记忆库接口.md](记忆库接口.md)。最常用的三个：`POST /characters/import` 导入角色；`GET /context?for=robot` 拿拼好的人设和记忆；`POST /events` 写一条聊天记忆。
- **数据**：`memory_data/<用户>/chars/<角色id>/` 下 `card.json`、`events.jsonl`、`profile.json`。内容相近（相似度 > 0.85）的记忆不重复记。
- **单独用**：`python3 memory/memory_server.py` 就能跑，端口 8900。不需要长期记忆整理就不配 `DASHSCOPE_API_KEY`。

## 2. 角色文件格式
- **做什么**：把一个故事里的人物变成机器人能用的角色。人设 8 个字段（名字、称呼、性格、说话方式、背景、关系、结局、相处方式）+ 声音 + 按时间排的经历。
- 格式见 [tasks/网页故事.md](../tasks/网页故事.md)，示例 `story1_linwan.json`。
- **从故事里提取的经验**：经历每条一句话，要有具体的物件、地点或原话（黄色雨伞、关东煮、"今天还好吗"），这些就是她开口会提到的细节；叙述里"你"指角色本人、"他"指用户；伤心事和温暖的事都要写，开场会自动避开伤心事。

## 3. 人设对话
- **做什么**：输入人设、记忆、对话历史、他这句话和语气，输出 JSON：`{emotion, expression, reply, remember[], end_session}`。
- **入口**：`llm.chat_turn(persona_text, memory_text, history, user_text, tone_cn, hint="")`。
- **规则文件**（纯文字，改了就生效）：`prompts/base_rules.md` 说话规则、记忆用法、已离世角色的规则；`prompts/emotion_rules.md` 情绪（开心、难过、生气、累、平静、想念）和表情的对应。
- **两道代码里的保护**（在 `brain.py`，对所有角色生效）：听到轻生相关的话，回答里一定劝他求助（关键词和兜底那句话在 `config.py` 的 `CRISIS_*`）；开场只挑温暖的经历、不编情节（`SAD_EVENT_WORDS`）。
- 模型输出偶尔不是标准 JSON，`_clean` 做了兼容。

## 4. 听
- **收音来源**：`MIC_SOURCE=mac` 用 Mac 麦克风；`MIC_SOURCE=head` 用机器人头的麦克风（adb 持续运行 `tinycap` 把声音流回 Mac，断了自动重连）。
- **判断说完**：按音量，安静 0.9 秒算说完；她说话时不收音，说完再多等 0.6 秒（头部收音有传输延迟）。
- **识别**：本地 SenseVoiceSmall，约 0.5 秒，同时给出语气标签（开心、难过等）。

## 5. 说
- **合成**：`tts.synthesize(text, voice_cfg)`。`voice_cfg` 例：`{"provider":"dashscope","voice":"Chelsie","backup":{"provider":"stepfun","voice":"jingdiannvsheng"}}`。主音色超时或出错就用备用音色。
- **播放**：`output.Speaker`。连着机器人头就发 `/audio/play`（嘴跟着动），否则用 Mac 喇叭。
- **网络**：所有请求都不走本机代理（`trust_env=False`，本机请求 `proxies` 里连 `all` 也设为 None）。

## 6. 机器人头连接
- **找机器人**：`tools/find_head.sh` 扫当前网段的 5555 端口，再用 adb 确认型号是 LubanCat。
- **启动**：`HEAD_IP=<IP> ./run.sh` 会启动孙博的 `head_motion_bridge.py`（端口 8787），并带上这台头必需的声卡设置（播放通道 `SPK_HP`、采样率 44100）。
- **自带应用**：大脑启动时停掉机器人自带的对话应用 `org.zksj.robot`，之后每 15 秒检查一次，被重新打开就再停掉。
- 细节和排错见 [tasks/机器人联调.md](../tasks/机器人联调.md)。

## 7. 对话大脑 + 演示控制台
- **大脑**（端口 8910）：一次相处开始时读当前角色的人设和记忆；每轮听 → 识别 → 想 → 先应一声"嗯" → 合成 → 说 + 做表情 → 值得记的写回记忆；道别或 3 分钟没说话就结束这次相处，并整理长期记忆。
- **控制台接口**：`GET /state`、`/memory`、`/characters`、`/avatar/<角色id>`；`POST /say`（打字代替说话）、`/session/start`、`/session/end`、`/character/activate`、`/reset`、`/head/recheck`、`/head/action`（手动动作）。
- **控制台页面**：角色照片（外圈颜色跟表情）、动作按钮、对话（每句的耗时）、人设和记忆、角色切换。
