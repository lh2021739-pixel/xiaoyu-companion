# 记忆库接口（v2：多角色、单向）

一句话：故事平台把一个角色（人设 + 经历）**导入**记忆库，记忆库把它标记为"当前角色"；机器人每次开始相处时，**读取**当前角色的人设和记忆，聊天中值得记住的事再**写回**这个角色名下。网页故事不再从记忆库读取。

- 地址：`http://127.0.0.1:8900`，跑在演示用的 Mac 上，只用 Python 自带库。
- 数据：`memory_data/<user_id>/chars/<character_id>/`，每个角色一个目录（`card.json` 人设、`events.jsonl` 记忆条目、`profile.json` 长期记忆），`active.json` 记录当前角色。各角色的记忆互不混用。
- 所有接口都可以带 `?user_id=`（默认 `demo`）和 `?character_id=`（默认当前角色）。

## 接口
| 接口 | 谁调用 | 作用 |
|---|---|---|
| `POST /characters/import` | 故事平台（一键导出） | 导入一个角色，默认设为当前角色。同 id 再次导入会覆盖。格式见 [tasks/网页故事.md](../tasks/网页故事.md) |
| `POST /characters/activate` `{"character_id":"..."}` | 控制台 | 切换当前角色 |
| `GET /characters` | 控制台 | 角色列表，标出当前角色 |
| `GET /context?for=robot` | 机器人大脑，每次开始相处时 | 返回 `persona_text`（人设）和 `memory_text`（记忆，已经拼好） |
| `POST /events` | 机器人大脑 | 写一条聊天记忆，`{"source":"robot","type":"said 或 emotion","summary":"一句第三人称的话"}`。内容相近的不会重复记 |
| `POST /profile/refresh` | 机器人大脑，一次相处结束时 | 把新聊的内容整理成长期记忆（关于他的事、喜好、约定、现在的状态），在后台进行 |
| `GET /all` | 控制台 | 当前角色的人设、全部记忆条目、长期记忆 |
| `POST /reset?scope=chat` | 控制台"清空聊天记忆" | 清空当前角色的聊天记忆，**保留导入的经历** |
| `POST /reset?scope=all` | 测试 | 清空全部 |

## 机器人读到的记忆长什么样（节选）
```
【你们一起经历过的事（来自故事，按时间）】
- 大学时，你们在图书馆抢同一本《小王子》认识……
- 去年深秋，你在他身边离开，最后一句话是"阿远，要好好的"。
【后来你们又聊过的】
- 他今天在公司被老板当众批评了，很累
【这段时间你记住的】
- 关于他：最近工作压力大
【他最近的情绪】
- 他说很想你（情绪：想念）
```
