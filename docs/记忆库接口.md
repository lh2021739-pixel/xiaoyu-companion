# 记忆库接口

一句话：故事平台把一个角色（人设 + 经历）**导入**记忆库，记忆库把它标记为"当前角色"；机器人每次开始相处时，**读取**当前角色的人设和记忆，聊天中值得记住的事再**写回**这个角色名下。网页故事不再从记忆库读取。

- 地址：`http://127.0.0.1:8900`，只用 Python 自带库。
- 数据：`memory_data/<user_id>/chars/<character_id>/`，每个角色一个目录（`card.json` 人设、`events.jsonl` 记忆条目、`profile.json` 长期记忆），`active.json` 记录当前角色。各角色的记忆互不混用。
- 所有接口都可以带 `?user_id=`（默认 `demo`）和 `?character_id=`（默认当前角色）。

## 接口
| 接口 | 谁调用 | 作用 |
|---|---|---|
| `POST /characters/import` | 故事平台（一键导出） | 导入一个角色，默认设为当前角色。同 id 再次导入会覆盖（包括清掉这个角色已有的聊天记忆）。格式见下文 |
| `POST /characters/activate` `{"character_id":"..."}` | 控制台 | 切换当前角色 |
| `GET /characters` | 控制台 | 角色列表，标出当前角色 |
| `GET /context?for=robot` | 机器人大脑，每次开始相处时 | 返回 `persona_text`（人设）和 `memory_text`（记忆，已经拼好） |
| `POST /events` | 机器人大脑 | 写一条聊天记忆，`{"source":"robot","type":"said 或 emotion","summary":"一句第三人称的话"}`。内容相近的不会重复记 |
| `POST /profile/refresh` | 机器人大脑，一次相处结束时 | 把新聊的内容整理成长期记忆（关于他的事、喜好、约定、现在的状态），在后台进行 |
| `GET /all` | 控制台 | 当前角色的人设、全部记忆条目、长期记忆 |
| `POST /reset?scope=chat` | 控制台"清空聊天记忆" | 清空当前角色的聊天记忆，**保留导入的经历** |
| `POST /reset?scope=all` | 测试 | 清空全部 |

## 机器人读到的记忆长什么样（节选）
```
【你们一起经历过的事（来自故事，按时间）】
- 大学时，你们在图书馆抢同一本《小王子》认识……
- 去年深秋，你在他身边离开，最后一句话是"阿远，要好好的"。
【后来你们又聊过的】
- 他今天在公司被老板当众批评了，很累
【这段时间你记住的】
- 关于他：最近工作压力大
【他最近的情绪】
- 他说很想你（情绪：想念）
```

## 导入格式
`POST /characters/import` 的请求体：
```json
{
  "character": {
    "id": "wife_001",
    "name": "角色名",
    "call_user": "她对用户的称呼",
    "personality": "性格",
    "speaking_style": "说话方式",
    "background": "她的身份和经历",
    "relationship": "和用户的关系",
    "ending": "故事的结局（例如她已经离开，自己也清楚）",
    "guidance": "现在和用户相处的方式（例如温柔陪他回忆，鼓励他好好生活）",
    "voice": {"provider": "dashscope", "voice": "Chelsie", "backup": {"provider": "stepfun", "voice": "jingdiannvsheng"}}
  },
  "events": [
    {"summary": "一句话写一段共同经历，按时间顺序", "importance": 1}
  ]
}
```
- `importance` 是 1 到 3；经历里"你"指角色本人，"他"指用户。
- `voice` 可以不填：`provider` 是 `dashscope`（百炼）或 `stepfun`（阶跃），`backup` 是主音色失败时的备用音色。
- 角色照片放在 `brain/avatars/<角色id>.jpg`，控制台会显示。
- 完整示例：`tools/sample_characters/story1_linwan.json`。
- 自测：
```bash
python3 memory/memory_server.py
python3 tools/import_character.py tools/sample_characters/story1_linwan.json
curl --noproxy '*' 'http://127.0.0.1:8900/context?for=robot'
```
