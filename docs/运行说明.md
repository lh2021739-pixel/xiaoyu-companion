# 运行说明

## 启动
**最省事：双击 `tools/双击启动.command`**（Mac 和机器人头连同一个手机热点）
- 自动在当前网络里找机器人头（开着 adb 5555 端口、型号是 LubanCat 的那台），找到的地址存在仓库根目录的 `.head_ip`，下次先试它；
- 启动头部控制程序、记忆库、大脑，**用机器人自己的麦克风收音**，停掉机器人自带的对话应用，打开控制台；
- 找不到机器人时会提示；输入 `m` 回车，就只用 Mac（Mac 麦克风和喇叭）；
- **关闭**：关掉那个终端窗口、按 Ctrl+C，或双击 `tools/双击关闭.command`，都会把所有程序和机器人录音一起关掉；
- 默认用 `python3`，要用别的 Python 就先 `export PYTHON=...`。

**命令行启动（接机器人）**：
```bash
HEAD_IP=<头部IP> PYTHON=<装好依赖的Python> ./run.sh
```
多出来的三件事：启动孙博的头部控制程序（AI-Lover 仓库，默认放在 `../partner/ai-lover`，可用 `HEAD_BRIDGE` 指定），声音从机器人喇叭出来；**用机器人自己的麦克风收音**；停掉机器人自带的对话应用（它会占住声卡、抢着回答，被重新打开也会自动再停掉）。Mac 上要装 adb。

**只用 Mac**（不接机器人，用 Mac 麦克风和喇叭）：
```bash
PYTHON=<装好依赖的Python> ./run.sh
```
这条命令会：
- 在 8900 端口启动**记忆库**；
- 在 8910 端口启动**机器人对话大脑**；
- 自动打开**演示控制台** http://127.0.0.1:8910。

`PYTHON` 要指向装了这些包的 Python（3.12 及以下）：numpy、sounddevice、funasr、torch、requests、scipy。新环境用 `pip install -r requirements.txt` 安装。

**导入角色**（第一次运行，或者要换一个角色时）：
```bash
python3 tools/import_character.py tools/sample_characters/story1_linwan.json   # 故事一：林晚（现在的演示角色）
```
故事平台导出时也可以直接调记忆库的导入接口。注意：**同一个 id 重新导入会清掉这个角色已有的聊天记忆**。

**角色照片**：控制台左上角显示 `brain/avatars/<角色id>.jpg`（也支持 png、webp），没有照片就显示表情脸。

**密钥**：放在仓库外面的 `../.keys.env`，不进仓库。
```
DASHSCOPE_API_KEY=...        # 必需：对话（qwen-flash）、语音合成（默认百炼）、整理长期记忆
STEPFUN_API_KEY=...          # 可选：百炼语音合成卡住时，自动改用阶跃
STEPFUN_BASE_URL=https://api.stepfun.com/step_plan/v1
```

**本地语音识别模型**：SenseVoiceSmall，默认放在 `~/.cache/modelscope/models/iic--SenseVoiceSmall/snapshots/master`，在别的位置时用 `SENSEVOICE_DIR` 指定。

**代理**：`run.sh` 启动时会清掉终端里的代理设置，所有请求一律直连。

## 常用开关（写在命令前面）
| 开关 | 作用 |
|---|---|
| `MIC=0` | 不开麦克风，只在控制台打字 |
| `MUTE=1` | 不出声（测试用） |
| `HEAD_IP=<头部IP>` | 接机器人头，自动启动头部控制程序，改用机器人麦克风 |
| `MIC_SOURCE=mac` | 接了机器人头，但仍用 Mac 麦克风收音 |
| `HEAD_URL=http://127.0.0.1:8787` | 头部控制程序已经手动启动时，只连过去 |
| `TTS_PROVIDER=stepfun` | 默认的语音合成改用阶跃（会慢一些） |
| `TTS_DASHSCOPE_VOICE=Serena` | 换百炼默认音色。角色资料里的 `voice` 字段优先 |
| `CHAT_MODEL=qwen-plus` | 对话改用 qwen-plus：更稳，但慢一倍 |
| `ACK=0` | 关掉"听完先应一声嗯" |
| `NO_OPEN=1` | 启动时不自动打开浏览器 |

**第一次开麦克风**：macOS 会弹窗请求麦克风权限，点"允许"。

## 控制台
- **左栏**：角色照片（没有照片时是表情脸；外圈颜色跟着表情变，说话时轻轻呼吸）、判断出的他的情绪、运行状态，以及"让她做个动作"按钮（微笑、难过、鬼脸、亲亲、眨眼、转眼睛、眨左眼、眨右眼、转头、复位），点一下机器人就做一次。
- **中栏**：对话，每句都标出想了多久、语音合成用了多久、声音从哪里播出。
- **右栏**：当前角色的人设卡片、长期记忆、记忆条目（"故事里的经历"和"和机器人聊的"分开显示），可以切换角色。
- **底部**：现场太吵时可以打字代替说话，还可以选择语气。另有开始相处、结束相处、清空聊天记忆（保留导入的经历）。

## 测试
记忆库和大脑都启动后运行：
```bash
python tests/e2e_text.py     # 打字模式，11 项检查。⚠️ 会清空 demo 用户的全部数据，跑完要重新导入角色
python tests/e2e_voice.py    # 语音模式，用 macOS 合成的声音模拟说话，走本地识别
```

## 机器人头
- 需要孙博团队 AI-Lover 仓库里的 `hardware/head_motion_bridge.py`（Python ≤3.12）和 adb；Mac 和机器人头连同一个热点。
- 这款头的声卡设置（播放通道 `SPK_HP`、采样率 44100）已写在 `run.sh` 里；机器人自带的对话应用会占住声卡，大脑启动时会自动停掉它。
- 手动检查：`curl --noproxy '*' http://127.0.0.1:8787/health`，`transport` 是 adb、`dry_run` 是 false 才算连上真机。
