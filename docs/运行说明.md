# 运行说明（演示用 Mac）

## 一条命令启动
```bash
PYTHON=<装好依赖的Python> ./run.sh
```
这条命令会：
- 在 8900 端口启动**记忆本**；
- 在 8910 端口启动**机器人大脑**；
- 自动打开**演示控制台** http://127.0.0.1:8910。

`PYTHON` 要指向装了这些包的 Python（3.12 及以下）：numpy、sounddevice、funasr、torch、requests。LH 电脑上阿璃项目的环境已经全部装好，上面的命令直接用它。其他电脑用 `pip install -r requirements.txt` 安装。

**密钥**：放在仓库外面的 `../.keys.env`，不进仓库。内容如下：
```
DASHSCOPE_API_KEY=...        # 必需：对话（qwen-flash）、整理长期记忆、语音合成的备用
STEPFUN_API_KEY=...          # 可选：阶跃语音合成（默认用它）
STEPFUN_BASE_URL=https://api.stepfun.com/step_plan/v1
```

**本地语音识别模型**：SenseVoiceSmall，默认路径是 `~/.cache/modelscope/models/iic--SenseVoiceSmall/snapshots/master`，LH 电脑上已经有了。放在别处时用 `SENSEVOICE_DIR` 指定。

## 常用开关（写在命令前面）
| 开关 | 作用 |
|---|---|
| `MIC=0` | 不开麦克风，只在控制台打字 |
| `MUTE=1` | 不出声（测试用） |
| `HEAD_URL=http://127.0.0.1:8787` | 接机器人头（见下一节） |
| `TTS_PROVIDER=dashscope` | 语音合成改用百炼，比阶跃快一倍 |
| `TTS_VOICE=qingchunshaonv` | 换阶跃音色；试听样本在 `../voice_samples/` |
| `CHAT_MODEL=qwen-plus` | 对话改用 qwen-plus，更稳，但慢一倍 |
| `ACK=0` | 关掉"听完先应一声嗯" |

**第一次开麦克风**：macOS 会弹窗请求麦克风权限，点"允许"。

## 接机器人头（等拿到头部 IP）
1. 头部和 Mac 连到同一个网络。
2. 启动头部控制程序。它在机器人同学的 AI-Lover 仓库里，本机路径是 `partner/ai-lover/hardware`：
   ```bash
   HEAD_MOTION_TRANSPORT=adb HEAD_MOTION_DRY_RUN=0 HEAD_MOTION_ADB_SERIAL=<头部IP>:5555 \
     <装好依赖的Python> head_motion_bridge.py
   ```
   要求 Python 3.12 及以下（它用到的 audioop 模块在 3.13 被删了），adb 在本机已安装。
3. 启动大脑时加上 `HEAD_URL=http://127.0.0.1:8787`。控制台顶部显示"机器人头已连接（真机）"就说明接上了。没有显示就点"重新检测机器人头"。
4. 接上之后，声音从头部喇叭出，嘴巴会跟着动，表情由大脑决定。没接上时，声音走 Mac 喇叭，表情只在控制台上显示。

## 演示流程
1. 演示前点"清空演示数据"（要连点两次确认）。
2. 网页故事里做一个选择，例如"陪你去看海"。故事平台会把选择写进记忆本，控制台右侧随即出现。
3. 对着 Mac 说"我回来了"。小屿会提起故事里的事。
4. 说"今天被老板骂了，好累"。小屿判断出难过，做难过的表情并安慰你，同时记下这件事。
5. 说"晚安"，这次相处结束，长期记忆自动整理（约定、喜好）。
6. 回到网页故事生成下一章，新的一章里会写到刚才和机器人聊的事。

**现场太吵时**：在控制台底部打字代替说话，可以选择语气，效果和说话一样。
