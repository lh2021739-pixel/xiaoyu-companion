# 运行说明（演示用 Mac）

## 启动
```bash
PYTHON=<装好依赖的Python> ./run.sh
```
这条命令会：
- 在 8900 端口启动**记忆库**；
- 在 8910 端口启动**机器人对话大脑**；
- 自动打开**演示控制台** http://127.0.0.1:8910。

`PYTHON` 要指向装了这些包的 Python（3.12 及以下）：numpy、sounddevice、funasr、torch、requests。新环境用 `pip install -r requirements.txt` 安装。

**导入角色**（第一次运行，或者要换一个角色时）：
```bash
python3 tools/import_character.py tools/sample_characters/wife_test.json
```
故事平台的一键导出做好后，导出时会直接写进记忆库，不需要这一步。

**密钥**：放在仓库外面的 `../.keys.env`，不进仓库。
```
DASHSCOPE_API_KEY=...        # 必需：对话（qwen-flash）、语音合成（默认百炼）、整理长期记忆
STEPFUN_API_KEY=...          # 可选：百炼语音合成卡住时，自动改用阶跃
STEPFUN_BASE_URL=https://api.stepfun.com/step_plan/v1
```

**本地语音识别模型**：SenseVoiceSmall，默认放在 `~/.cache/modelscope/models/iic--SenseVoiceSmall/snapshots/master`，在别的位置时用 `SENSEVOICE_DIR` 指定。

**代理**：大脑调百炼和阶跃时一律直连，不读本机的代理设置。代理会让音频下载变慢，SOCKS 代理还会直接报错。

## 常用开关（写在命令前面）
| 开关 | 作用 |
|---|---|
| `MIC=0` | 不开麦克风，只在控制台打字 |
| `MUTE=1` | 不出声（测试用） |
| `HEAD_URL=http://127.0.0.1:8787` | 接机器人头（见 tasks/机器人联调.md） |
| `TTS_PROVIDER=stepfun` | 默认的语音合成改用阶跃（会慢一些） |
| `TTS_DASHSCOPE_VOICE=Serena` | 换百炼音色。角色资料里的 `voice` 字段优先 |
| `CHAT_MODEL=qwen-plus` | 对话改用 qwen-plus：更稳，但慢一倍 |
| `ACK=0` | 关掉"听完先应一声嗯" |
| `NO_OPEN=1` | 启动时不自动打开浏览器 |

**第一次开麦克风**：macOS 会弹窗请求麦克风权限，点"允许"。

## 控制台
- **左栏**：角色的表情脸、判断出的他的情绪、运行状态。
- **中栏**：对话，每句都标出想了多久、语音合成用了多久、声音从哪里播出。
- **右栏**：当前角色的人设卡片、长期记忆、记忆条目（"故事里的经历"和"和机器人聊的"分开显示），可以切换角色。
- **底部**：现场太吵时可以打字代替说话，还可以选择语气。另有开始相处、结束相处、清空聊天记忆（保留导入的经历）。

## 测试
记忆库和大脑都启动后运行：
```bash
python tests/e2e_text.py     # 打字模式，11 项检查。会清空 demo 用户的数据，并重新导入两个测试角色
python tests/e2e_voice.py    # 语音模式，用 macOS 合成的声音模拟说话，走本地识别
```
